# Martini 3 force-field files

Not stored in this repository. Run `bash ff/get_martini_ff.sh` to download `martini_v3.0.0.itp`, `martini_v3.0.0_ions_v1.itp` and `martini_v3.0.0_solvents_v1.itp` from the Martini Force Field Initiative (`M3-Lipid-Parameters`). If `git clone` is blocked, take the same files from the Martini 3 downloads page at cgmartini.nl.
